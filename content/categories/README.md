# Categorías

Guarda cada categoría en un archivo JSON individual de este directorio,
siguiendo `content/categories.schema.json`. Usa un `id` estable en minúsculas
separado por guiones. Todo producto debe referirse a una categoría existente y
activa antes de generar el catálogo.

No hay categorías comerciales confirmadas en este repositorio. Añádelas cuando
Medipiel valide sus nombres y clasificación.
